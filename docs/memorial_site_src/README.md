# KidsPGフェス2025 記念サイト 資材

## 概要

「KidsPGフェス2025」で展示された、マイスター・ギルド社のゲームコンテンツ「よけまくり中」のプレイ記念メモリアルカード配布サイトに関連する資材一式です。

## ファイル構成

| ファイル名                                       | 説明                                                                                                                            |
| :----------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| `2025-memorial-gallery.html`                     | プレイヤーごとにAIが生成したメモリアルカードを閲覧・ダウンロードできるギャラリーページのHTMLファイルです。                          |
| `2025-yokemakuri-memorial.html`                  | ゲームのプレイ中やイベント会場で表示された、メモリアルカード配布サイトへの案内ページです。                                        |
| `card_images.zip`                                | `2025-memorial-gallery.html`で表示される全てのカード画像を格納したZIPファイルです。                                               |
| `game_title_image.png`                           | サイトのOGP画像などで使用されるゲームのタイトル画像です。                                                                       |
| `neko.png`                                       | サイトのアイコンやページ内で使用されている猫のキャラクター画像です。                                                            |
| `favicon.ico`                                    | ブラウザのタブなどに表示されるファビコンです。                                                                                  |
| `KidsPG2025-メモリアルカード掲載サイト紹介_MG.pptx` | イベント関係者や内部向けの、本サイトに関する説明資料（PowerPoint形式）です。                                                    |
| `KidsPG2025-メモリアルカード掲載サイト紹介_MG.pdf`  | 上記PPTXファイルのPDF版です。                                                                                                   |
| `memorial_card_*.png`                            | 上記PPTXファイルに張り付けたサンプルの生成AI画像です         |
| `game_title_image.xcf`                           | `game_title_image.png`の元となった、画像編集ソフトGIMPのプロジェクトファイルです。                                                |
| `neko.xcf`                                       | `neko.png`の元となった、画像編集ソフトGIMPのプロジェクトファイルです。                                                            |
